## Navigation and page numbers

- **Table of contents with live page numbers.** Page 3 carries a real Word `TOC` field covering chapters, numbered sections and sub-sections.
- **To refresh all page numbers in one action:** press **Ctrl + A**, then **F9**. If Word asks, choose **"Update entire table"**. This updates both the contents list and the Page column of the syllabus map together. Word also offers to refresh the fields automatically each time the file is opened.
- **Bookmarks.** All 12 chapters are wrapped in named Word bookmarks (`Ch01`–`Ch11`, `ChA`), and every chapter, section and sub-section uses genuine Heading 1/2/3 styles — so they all appear in the **Navigation Pane** (*View → Navigation Pane*) as clickable links.
- **Ctrl + click** any contents entry to jump straight to it.
- **Exporting to PDF:** choose *Save As → PDF → Options* and tick **"Create bookmarks using: Headings"** to carry the chapter sidebar into the PDF.
